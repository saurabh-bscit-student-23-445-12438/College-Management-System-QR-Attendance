# College Management System with QR Attendance

A complete College Management System developed using HTML, CSS, Flask, MySQL, and OpenCV.  
This system manages students, faculty, attendance, fees, notices, and reports in an efficient way.

---

## Features

### Student Panel
- Login Authentication
- View Profile (Name, Roll No, Department, Course, Address)
- QR Code for Attendance
- Attendance History (with Faculty Name)
- Fee Details (Total, Paid, Pending)
- Notice View
- Logout System

---

### Faculty Panel
- Login Authentication
- View Profile
- Subject Selection
- QR Code Attendance System (Camera Scan)
- Attendance Records
- Notice View
- Logout System

---

### Admin Panel
- Admin Login
- Add / Delete / View / Search Students
- Add / Delete / View / Search Faculty
- Manage Courses & Subjects
- Fee Management System
  - Set Total Fee
  - Add Payment
  - View Fee History
- User Contact Management
- Notice Management
- Generate Reports (Excel Download):
  -  Attendance Report
  -  Student Report
  -  Faculty Report
  -  Course & Subject Report
  -  Fee Report
  -  Notice Report
  -  Daily Activity Report
  -  Logout System

---

## Technologies Used

- **Frontend:** HTML, CSS, Bootstrap  
- **Backend:** Flask (Python)  
- **Database:** MySQL  
- **QR System:** OpenCV & qrcode  
- **Reports:** Pandas, OpenPyXL
